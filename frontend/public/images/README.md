# Panduan File Foto & Gambar

Simpan file foto Anda di dalam subfolder berikut agar rapi dan terorganisir:

### 1. `frontend/public/images/mempelai/`
Untuk foto kedua pengantin dan foto utama (hero):
- `pria.jpg` (Foto arch pengantin pria Rizal Pratama)
- `wanita.jpg` (Foto arch pengantin wanita Putri Anindya)
- `hero.jpg` (Foto latar belakang utama)
- Cara pakai di JSX: `<img src="/images/mempelai/pria.jpg" alt="..." />`

### 2. `frontend/public/images/gallery/`
Untuk galeri dokumentasi foto:
- `prewed-1.jpg`, `prewed-2.jpg`, ...
- `sunda-1.jpg`, `sunda-2.jpg`, ...
- `casual-1.jpg`, `casual-2.jpg`, ...
- Cara pakai di JSX: `src: "/images/gallery/prewed-1.jpg"`

### 3. `frontend/public/images/story/`
Untuk foto perjalanan cinta (Love Story):
- `2020.jpg` (Pertama bertemu)
- `2022.jpg` (Menjalin hubungan)
- `2025.jpg` (Hari lamaran)
- `2026.jpg` (Menuju pelaminan)

> **Tips Ukuran**: Kompres gambar ke format `.webp` atau `.jpg` dengan resolusi maksimal `1920x1080` (ukuran file di bawah 500KB per foto) agar website terbuka super cepat dan ringan di HP para tamu.
